# ⚡ HPC & Big Data — Midterm Exam Prep

Интерактивный веб-тренажер для подготовки к мидтерм-экзамену по курсу **High Performance Computing & Big Data** (50 вопросов из официального пула подготовки к Moodle тесту).

---

## 🎯 Основные возможности

1. **🔀 Полное перемешивание (Shuffling)**:
   - **Shuffle Questions**: Вопросы перемешиваются в случайном порядке.
   - **Shuffle Options (A–E)**: Варианты ответов внутри каждого вопроса перемешиваются местами. Приложение автоматически отслеживает правильный ответ по смыслу, а не по фиксированной букве!
   - Кнопка **Reshuffle Now**: Мгновенный сброс и новая случайная генерация.
   - Кнопка **Original Order**: Возврат к оригинальному порядку из PDF (вопросы 1–50).

2. **📚 4 режима обучения**:
   - 🎯 **Practice (Практика)**: Мгновенная проверка ответа (зеленый / красный), разбор и пояснение каждого концепта/формулы.
   - ⏱️ **Exam Simulation (Симуляция Moodle)**: 45 минут таймер, сетка навигации по 50 вопросам, флажки, подсчет финального балла и детальная статистика по темам.
   - 🃏 **Flashcards (Флеш-карточки)**: Быстрое повторение формул и терминов по клику.
   - 📋 **Cheat Sheet & Search (Шпаргалка)**: Поиск по ключевым словам (`MPI_Reduce`, `SIMD`, `FLOP`, `HDFS`, `firstprivate`), переключатель показа всех ответов.

3. **📊 Фильтрация по 5 темам**:
   - ⚡ HPC Fundamentals (10 вопросов)
   - 🧠 Memory and parallel design (10 вопросов)
   - 🌐 MPI (10 вопросов)
   - 🧵 OpenMP and hybrid programming (10 вопросов)
   - 🗄️ MapReduce and distributed storage (10 вопросов)
   - ⭐ Избранное / Ошибки (быстрый доступ к сложным вопросам)

4. **⌨️ Горячие клавиши (Keyboard shortcuts)**:
   - `1` – `5` или `A` – `E` — быстрый выбор варианта ответа
   - `←` / `→` или `Enter` / `Space` — переход к следующему / предыдущему вопросу
   - `S` — добавить в избранное
   - `R` — перетасовать (Reshuffle)

5. **🌙 Темы и звук**:
   - Dark mode & Light mode
   - Звуковые эффекты через синтезатор Web Audio API (работает автономно без внешних аудиофайлов).

## 🚀 Как запустить локально

Просто откройте файл `index.html` в любом браузере:
```bash
open index.html
```
Или запустите локальный сервер:
```bash
python3 -m http.server 8000
```
И откройте в браузере: `http://localhost:8000`

## 🌐 Как выложить в GitHub Pages

### Шаг 1: Создайте новый репозиторий на GitHub
1. Перейдите на [github.com/new](https://github.com/new)
2. Назовите репозиторий, например: `hpc-midterm-prep` (сделайте его **Public**)
3. Не создавайте README / .gitignore (они уже готовы в проекте).

### Шаг 2: Привяжите и запушьте код
В терминале внутри этой папки выполните:
```bash
git remote add origin https://github.com/<ВАШ_GITHUB_USERNAME>/hpc-midterm-prep.git
git push -u origin main
```

### Шаг 3: Включите GitHub Pages
1. В вашем репозитории на GitHub перейдите в **Settings** → **Pages** (в левой колонке).
2. В разделе **Build and deployment**:
   - **Source**: выберите **Deploy from a branch**.
   - **Branch**: выберите `main`, папку `/ (root)`, и нажмите **Save**.
   *(Или выберите **GitHub Actions**, если хотите деплой через готовый workflow).*
3. Через 1-2 минуты сайт будет доступен по ссылке:
   `https://<ВАШ_GITHUB_USERNAME>.github.io/hpc-midterm-prep/`
